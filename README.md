# international-soccer-predictor
Using Dixon-Coles model, this application simulates a projected scoreline and win, loss, and draw probabilities between any two international soccer teams. The attacking and defensive strengths of a team are calculated using linear regression of historical data between opponent quality (using FIFA ranking points) and goals scored/conceded. The predictor can be found here: https://justusward.shinyapps.io/world_cup_project/
